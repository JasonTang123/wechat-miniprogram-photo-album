## 在微信里「能打开」的两条路

| 路径 | 能否被陌生人搜索到 | 速度 |
|------|-------------------|------|
| **测试号** + 开发者工具「预览」扫码 | 否，仅本人/扫码打开 | 最快 |
| **正式注册** → 上传 → 提审 → **发布** | 是（审核通过后） | 需主体信息与审核 |

本阶段目标：先跑通「手机微信能打开占位首页」。公开搜索需走正式发布。
